### 执行上下文

```js
function foo(a){
    var b=2;
    function c(){}
    var d = function(){}
    b=3;
}
foo(1);
```

- 执行上下文的创建阶段

- 函数的定义、声明
- 变量的声明
- 函数的形参
- 没有实际传入参数的arguments
- var声明的变量提升为undefinted

上述代码的此过程
```
<!-- 活动对象，activity object,属于函数上下文中的 -->
<!-- 变量对象，属于全局上下文中的，存的是全局变量和全局函数 -->
AO ={
    <!-- 入参的过程:如果有参数则入参，没有也会有对应的length属性 -->
    arguments:{
        0:1,
        length:1
    }
    a:1,
    b:undefinted,
    c:reference to function c(){}
    d:undefinted,
    <!-- //d是函数表达式。相当于一个变量，是变量提升，而不是函数的引用 -->
    <!-- ！！！函数表达式和函数声明的区别 -->
    <!-- 函数表达式相当于定义了一个变量 -->
}
```
