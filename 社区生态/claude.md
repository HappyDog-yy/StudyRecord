### 缺的不是智商，而是经验：为什么通用 Agent 还是难干活
今天的通用 Agent 也一样：它很聪明，但经常在真实工作里卡住，通常是三类问题：
- 背景缺失：组织里的约定、历史决策、合规红线，模型默认不知道
- 复用困难：同类任务反复做还是出错，质量靠人盯
- **不会自我固化：这次踩过的坑，下次还会踩，因为经验没有被沉淀成资产**

### Skills 的本体：把 SOP 做成可版本化文件资产 

Skills 是一组文件的组织方式，用来打包领域专业知识与程序化流程。
- **Skill带来的工程属性**
- 版本化：用git做review，能回滚、追责
- 可共享：能放在仓库、共享盘、团队目录里
- 可审计：流程与边界写在文件里，而不是散在对话里

### 渐进式披露：让技能规模增长但上下文成本可控

三层账本
- 元信息：只暴露name/description,token成本低
- 入口：命中后才加载
- 附录：需要细节再按需读

### description 不是简介，更像路由规则

- 它告诉模型两件事
- 什么时候用它，用了之后的产出是什么

- 把真实触发词写进去
- 把产出说具体，而非抽象能力，报告、表格、代码改动、检查清单

### 脚本即工具，把确定性工作交给代码

### Skill、MCP、Subagents 怎么分工 

- SKill:怎么做（流程、模板、检查点、验收方式）
- MCP:连到哪里，外部工具与数据源的连接层
- sunagengt:怎么分工

### 术语

- Prompt:本次任务指挥：输入、约束、验收
- 产物是一段任务描述
- Project:长期背景、资料沉淀
- 产物是项目级文档
- Skills:稳定做法：流程、边界、验收、模板、脚本入口
- MCP:外部系统接入
- 产物是连接配置与工具接口
