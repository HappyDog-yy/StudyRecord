### 1.let关键字声明了一个块级作用域的局部变量

- 声明的变量仅仅在作用域内有效
- 在for循环之外访问变量i，会出错
- 每次循环有自己的i变量

```js
for(let i=0;i<5;i++){
    setTimeout(function () {
            console.log(i);
    },1000)
}

// for循环外部访问变量i出错
// 1s之后执行0 1 2 3 4
// 创建5个计时器，但是5个计时器的创建几乎是同时的
// 因此看起来1s之后，五个计时器同时输出01234
```

将上述代码中的let改成var，会输出什么？

```js
for(var i=0;i<5;i++){
    setTimeout(function () {
            console.log(i);
    },1000)
}

// 输出5个5
// 因为var没有块级作用域，所有变量共享一个i，使用的是1s之后的i
```

- 为什么一个输出的是4，一个是5
- 对于for(条件1，条件2，自增)
- 条件1，初始化，只执行一次-->条件2-->自增

- 5次循环的执行过程如下
- i=0，i<5,i++,let记住i=0
- i=1，i<5,i++,let记住i=1
- i=2，i<5,i++,let记住i=2
- i=3，i<5,i++,let记住i=3
- i=4，i<5,i++,let记住i=4
- 此时i=5，不满足循环条件，不进入循环
- 循环结束之后，i的值变成5了

- 因此let定义变量输出0 1 2 3 4
- var定义变量输出5个5（相当于定义了一个全局的i，var没有块级作用域）


### 2.函数的词法环境和变量环境分析

- **变量环境**
- 存储var声明的对象
- 块内的var声明的变量也会存储到这里
- 在整个函数执行期间都存在

- **词法环境**
- 存储let/const声明的变量
- 分为多个层级，函数/块
- 块级作用域结束后，对应的词法环境销毁
- 内层可以遮蔽外层的同名变量

- **变量查找规则**
- 1.当前词法环境
- 2.链式查找外层词法环境
- 3.变量环境
- 4.外层函数/全局

```js
function foo() {
    var a_var = 1;
    let b_let = 2;
    {
        let b_let = 3;
        var c_var = 4;
        let d_let = 5;
        console.log('a_var',a_var);
        console.log('b_let',b_let);
    }
    console.log('b_let',b_let);
    console.log('c_var',c_var);
    console.log('d_let',d_let);
}
foo();
```

1.foo的变量环境(var)-->存a_var=undefined、c_var=undefined
  foo的词法环境(let,const)-->b_let(啥也没有，没有undefinted)

2.foo的变量环境(var)-->存a_var=1、c_var=undefined
  foo的词法环境(let,const)-->b_let = 2

3.此时执行到块级作用域
  foo的变量环境(var)-->存a_var=1、c_var=4
  foo的词法环境(let,const)-->b_let = 2
    此时词法环境中再包含一个块级作用域
    块级词法环境：b_let = 3(遮蔽外层的2),d_let = 5

4.块级作用域中的输出 1-->3
    块级词法环境在执行完之后被销毁
    foo的变量环境(var)-->存a_var=1、c_var=4
    foo的词法环境(let,const)-->b_let = 2

5.外层输出：2 4 报错：未定义

### 3.switch语句如果不加花括号的话，只有一个块级作用域

- 不能在同一个作用域中使用let重复声明变量
- 报错：Uncaught SyntaxError: Identifier 'x' has already been declared
- 在每一个case之后加上{}即可

```js
let num = 1;
switch(num){
    case 1:
        let x=1;
        console.log(x);
        break;
    // case 2:
    //     let x=3;
    //     console.log(x);
    //     break;
    // 花括号：创建独立块
    case 2:{
        let x=3;
        console.log(x);
        break;
    }   
}
```

### 4.箭头函数的this指向

- **普通函数的this指向**
- 取决于函数的调用方式：谁调用该函数，this就指向谁
- 优先级：new>显示绑定(call,apply,bind)>隐式(调用该函数的对象)>默认(全局对象)
- 默认情况下，普通函数的指向是什么？？？？
    - 非严格模式：全局对象
    - 严格模式：undefinted

- **箭头函数中的this**
- 箭头函数没有自己的this
- 其中的this指向哪里取决于(继承自)**定义时**外层的作用域
- 且一旦继承，终身不变
- 显示绑定方法call apply bind对其无效
- 直接继承外层第一个普通函数的this
- 如果外层没有函数，就指向全局变量，严格模式下指向undefinted

- **显式绑定的些许差异**
- call和apply是即时执行
- bind是永久绑定，返回一个函数，执行时机取决于返回函数的调用时机
- bind绑定是硬绑定，绑定之后就不能再修改了，之后再使用call和apply也不会覆盖this

- 在dom事件回调中，this指向触发事件的dom元素

#### 4.1
```js
var name = 'window';
function foo() {
    console.log(this);
}
let obj = {
    name:'object',
    normal:function(){console.log(this.name)},
    arrow:()=>{console.log(this.name)}
};
obj.normal();
obj.arrow();
foo();
// 输出：object,window和window对象
```

normal函数：普通函数，通过对象的属性调用，指向调用它的对象obj,输出obj.name=object
arrow函数：箭头函数，它的this取决于定义时的外层作用域，没有外层函数，指向全局对象（window）,输出windows.name = window
如果使用严格模式，调用arrow输出undefinted

#### 4.2

var name = 'global';
let obj={

const fn = obj.noraml;

- 调用时没有使用属性.方法，是独立调用，指向全局对象，输出global

#### 4.3

```js
var name = 'global';
obj = {name:'jojo'};

function normal() {
    console.log(this.name);
}
const arrow = ()=>{console.log(this.name)}

normal.call(obj);
arrow.call(obj);
// 输出jojo global
```

- 可见显示绑定this对于箭头函数无效，箭头函数对显示绑定免疫

#### 4.4

```js
var name = 'Global';
const obj = {
    name: 'Object',
    run: function() {
        // 内部函数
        function innerNormal() { console.log(this.name); }
        const innerArrow = () => { console.log(this.name); }

        innerNormal(); // ❓
        innerArrow();  // ❓
    }
};
obj.run();
// 输出global和object
```
- innerNormal:普通函数，调用时独立调用，this指向全局对象
- innerArrow:箭头函数，继承外层函数的this，外层函数作为obj的属性调用，指向obj
- 因此该箭头函数的this也指向obj，输出obj.name = Object

#### 4.5

```js
function Person(name) {
    this.name = name;
    this.normal = function() { console.log(this.name); };
    this.arrow = () => { console.log(this.name); };
}

const p = new Person('Jack');
p.normal(); // ❓
p.arrow();  // ❓
// 输出Jack，jack
```
- normal:普通函数，this指向取决于它的调用方式，通过p的属性调用，指向p，输出Jack
- arrow:箭头函数，this指向取决于定义时的外层函数this指向，外层函数由p调用，this指向为p

#### 4.6 settimeout

```js
var name = 'Global';
const obj = {
    name: 'Object',
    delay: function() {
        setTimeout(function() { console.log('Normal:', this.name); }, 100);
        setTimeout(() => { console.log('Arrow:', this.name); }, 100);
    }
};
obj.delay();
// 输出global，object
```

- 第一个是普通函数，作为回调函数调用，也是独立调用，this指向全局对象，100ms后输出Global
- 第二个是箭头函数，取决于定义时外层函数的this，即delay的，delay的this指向obj，输出object

#### 4.8终极混合

```js
var name = 'Global';
const obj = {
    name: 'Object',
    foo: function() {
        return () => { console.log(this.name); };
    },
    bar: function() {
        return function() { console.log(this.name); };
    }
};

const a = obj.foo();
a(); // ❓

const b = obj.bar();
b(); // ❓

// 输出object和global
```

- foo函数是普通函数，作为obj的属性调用，this指向obj，函数体为空，不执行任何代码
- a变量接受其返回值，a是一个箭头函数，它的this取决于定义时的外层函数，指向obj，调用a输出object
- bar函数是普通函数，也作为obj的属性调用，this指向obj，函数体为空，不执行
- b接受bar的返回函数，b是一个普通函数，它的this取决于调用方式，独立调用，指向全局，输出global
